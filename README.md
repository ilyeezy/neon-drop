# GAME_NAME — блок-пазл для Яндекс Игр

Головоломка на сетке: трей из трёх фигур, перетаскивание на поле, сгорание заполненных строк и столбцов. Ванильный JavaScript (ES2022, ES-модули) + Canvas 2D, ноль зависимостей, ноль внешних запросов.

## Запуск локально

Нужен любой статический сервер из корня проекта (ES-модули не работают по `file://`):

```bash
python -m http.server 8000
```

Затем открыть `http://localhost:8000/`. SDK Яндекса локально отсутствует — платформенный слой автоматически подставляет заглушку (`src/platform/stub.js`): сохранения идут в `localStorage`, реклама — мгновенные no-op вызовы.

## Проверки

Тесты ядра, генератора, drag-логики, платформы и сохранений:

```bash
node --test tests/*.test.js
```

Автотест генератора — случайный бот доказывает честность выдачи, жадный меряет длину партии:

```bash
node tools/autotest.js
```

Верификатор уровней — каждый уровень прогоняется двумя ботами: с нулевым запасом бустеров (обязан быть проходим) и с максимальным (не должен схлопываться тривиально):

```bash
node tools/verify-levels.js 8
```

## Сборка архива для Консоли разработчика

В архив идёт **только** содержимое игры. Из корня проекта:

```bash
zip -r game.zip index.html style.css src assets -x "*.DS_Store"
```

В архив **не** входят: `docs/`, `tests/`, `tools/`, `.claude/`, `.git/`, `AGENTS.md`, `CLAUDE.md`, `README.md`, `package.json`.

Требования, которые архив уже выполняет: `index.html` в корне, только латиница в именах файлов, SDK подключён относительным путём `<script src="/sdk.js">` до своего кода, нет абсолютных URL и внешних запросов, размер — сотни килобайт.

## Настройки черновика в Консоли

Включить и заполнить руками:

1. **Монетизация** — сама реклама включается в Консоли; в коде вызовы уже есть (interstitial на экране результата, rewarded за бустеры/темы/второй заход в ежедневный вызов).
2. **Sticky-баннер** — настраивается только в Консоли, код его не трогает; вёрстка пересчитывается по `visualViewport.resize`.
3. **Облачные сохранения** — обязательно включить: игра пишет прогресс через `player.setData` (плюс зеркало в `localStorage`).
4. **Ориентации** — включить обе (портрет и ландшафт), лейаут поддерживает обе.
5. **Платформы** — desktop + mobile. **Android TV в первой подаче не заявлять**: клавиатурная схема есть, но ТВ требует отдельной проверки по п. 1.6.3 и своего UX для drag — это отдельный релиз (v1.1).
6. **Язык** — русский и английский; игра сама определяет язык через `ysdk.environment.i18n.lang`.

## Что нужно сделать руками

- **Название игры.** В коде и локалях стоит плейсхолдер `GAME_NAME` — заменить во всех файлах: `src/i18n/ru.js`, `src/i18n/en.js`, `index.html` (`<title>`).
- **Шрифт.** Сейчас используется системный стек (`system-ui`) — внешних загрузок нет. Если нужен фирменный шрифт, положить `.woff2` с открытой лицензией (SIL OFL) в `assets/fonts/` и раскомментировать блок `@font-face` в `style.css`.
- **Иконка и обложка** — по требованиям Консоли.
- **Скриншоты** — реальный геймплей ≥ 70% кадра, без рамок и скруглений, без элементов системного интерфейса.
- **Тексты «Об игре» и «Как играть»** — стоит подчеркнуть отличители: режим задач со спецблоками, ежедневный вызов, честная раздача, разблокируемые темы (это защита от отказа по п. 3.6 «дубликат жанра»).

## Структура

```
index.html          точка входа, подключение SDK
style.css           базовый CSS платформы + стеклянный UI
src/
  main.js           оркестрация, rAF-цикл, системные паузы
  core/             битборд, фигуры, постановка, очистка, очки, генератор, FSM
  render/           канвас-рендер, спрайты, частицы, фон, темы
  input/            чистая drag-логика, pointer-обвязка, клавиатура
  audio/            процедурный WebAudio
  platform/         обёртка SDK, заглушка, политика рекламы
  save/             схема сейва, версия, миграции
  content/          режимы, цели, прогресс, туториал, оркестратор партии
  levels/           20 уровней режима задач
  ui/               экраны, адаптивный лейаут
  i18n/             ru + en
docs/               HLD, LLD и EARS-спеки по сегментам (в архив не идут)
tests/              юнит-тесты (node --test)
tools/              автотест генератора, верификатор уровней, боты
```

Документация проекта: архитектура — `docs/high-level-design.md`, дизайн и спеки сегментов — `docs/intent/*/`, исходное ТЗ — `docs/reference/spec-yandex-games.md`.
