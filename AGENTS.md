# GAME_NAME — блок-пазл для Яндекс Игр

Головоломка на сетке (8×8, параметризуемо до 9×9 и 10×10): трей из трёх фигур, drag & drop на поле, сгорание заполненных строк и столбцов. Ванильный JavaScript (ES2022, ES-модули) + Canvas 2D, без сборщика и без зависимостей. UI-экраны — HTML/CSS, поле и эффекты — canvas. Звук — только WebAudio API. Полное ТЗ заказчика: `docs/reference/spec-yandex-games.md`. Архитектура: `docs/high-level-design.md`.

## Команды

- Локальный запуск: статический сервер из корня, например `python -m http.server 8000`.
- Тесты ядра и генератора: `node --test tests/` (встроенный раннер Node, без зависимостей).
- Автотест генератора (появится на этапе 3): `node tools/autotest.js` — два бота: случайный (доказывает ноль несправедливых проигрышей на 1000 партий) и жадный (меряет длину партии играющего; порог фиксируется по первым замерам).
- Замер помощи игроку: `node tools/help-check.mjs` — доля треев с фигурой под очистку и число сгораний за партию, с щадящей выдачей и без.
- Замер жалости: `node tools/mercy-check.mjs` — три конфигурации (выключена / по порогам / всегда) с длиной партии, очками и долей раздач со срабатыванием.
- Верификатор уровней (появится на этапе 7): `node tools/verify-levels.js` — два прогона на уровень: при нуле бустеров уровень проходим (п. 4.5.2), при максимальном запасе — не проходится тривиально. Отвергает раскладки с золотом на льду/камне.

## Правила проекта

- Запрещённые слова везде (код, тексты, локали, комментарии, коммиты): «Block Blast», «Блок Бласт», «1010», «Tetris», «тетрис», «тетромино». Фигуры называются «фигуры»/«блоки», в коде — по форме (`L3`, `I4`, `SQ3`, `T4` и т.п.).
- Название игры — плейсхолдер `GAME_NAME` в коде и локалях.
- Никаких внешних запросов: CDN, Google Fonts, аналитика, сторонние API запрещены.
- Ни одного тега `<audio>` / `<video>`; только WebAudio. `navigator.mediaSession` не трогать.
- Клавиатура читается только по `event.code` (не `key`, не `keyCode`).
- Ввод drag — только Pointer Events; отдельных веток `touchstart`/`mousedown` не существует.
- Случайность — только через инжектированный PRNG (mulberry32); `Math.random()` в игровом коде запрещён.
- В именах файлов и папок — только латиница, цифры, дефис, подчёркивание.
- В архив для Консоли разработчика НЕ входят: `docs/`, `tests/`, `tools/`, `AGENTS.md`, `CLAUDE.md`, `.git`, `README.md`, `package.json`.

## Чек-лист приёмки сборки

- `BALANCE.generator.mercyAlwaysOn` обязан быть `false` — это отладочный флаг, в релизном архиве жалость работает только по порогам.
- Тесты `node --test tests/` и верификатор `node tools/verify-levels.js` зелёные.
- В архив не попали `docs/`, `tests/`, `tools/`, `AGENTS.md`, `CLAUDE.md`, `.git`, `README.md`, `package.json`.

## Глубина процесса по сегментам

| Сегменты | Процесс |
|---|---|
| `CORE`, `GEN`, `PLAT`, `SAVE`, логика `INPUT` | Полный цикл LID: LLD → EARS → тесты → код |
| DOM-обвязка `INPUT`, `RENDER`, `AUDIO`, `UI` | LLD без EARS и юнит-тестов; проверка глазами |
| `CONTENT` | LLD без EARS; вместо юнит-тестов — обязательный `tools/verify-levels.js` (солвер решаемости уровней) |

- Логика `INPUT` — чистая часть drag: координаты → клетка, решение о снапе, валидация постановки, состояние drag. Тестируется без DOM.
- `PLAT`: реальный SDK юнит-тестами не покрывается; тестируется обёртка против `stub.js` — в этом смысл обёртки.
